# 国家数据集团综合能力刷题 · 本地版

支持电脑与手机刷题、好题收藏、错题本和三个独立的本地练习档案，无需登录。

## 下载和运行

- `quiz-local-20261125.zip`：完整本地部署包，含电脑网页、Mac / Windows 手机扫码启动器和使用说明。
- `quiz.html`：独立网页文件，下载后直接用浏览器打开即可练习。

电脑：完整解压 ZIP，打开其中的“综合刷题.html”。

手机：电脑和手机接入同一 Wi-Fi，Mac 双击“启动手机扫码版.command”，Windows 双击“启动手机扫码版.bat”，再用手机浏览器扫码打开。启动器需要 Python 3.7+ 或 Node.js 16+，电脑启动窗口需保持运行。

GitHub 的文件预览页不直接运行 HTML，请先下载到本机。

## 题库内容

资料核对至 2026 年 11 月 25 日。共 1205 条题目与材料，其中 1198 道可判分单选、4 条运营商回忆材料、3 条北森原库待核材料。

| 分组 | 数量 |
| --- | ---: |
| 北森原库 | 719（716 道可练、3 条待核） |
| 时政与数据政策 | 140 |
| 数据专业与理论 | 140 |
| 企业管理 | 30 |
| 行测加练 | 30 |
| 股权投资岗 | 10 |
| 运营商公开整理题及回忆材料 | 16 |
| 半月谈公开选编 | 60 |
| 粉笔公开选编 | 60 |

三套综合模拟卷各 60 分钟、50 题，每套均为行测 20 题、政策 10 题、数据 10 题、企业管理 10 题。

半月谈和粉笔分组依据公开练习、报道或讲解进行选编，逐题标明改编或自编性质、出处与独立解析，不是机构完整商业题库或原题原解析。具体来源可在网页“题源资料”查看。

北森原始项目来源：<https://github.com/minnielv/beisen-quiz>。

## 记录和备份

页面顶部可切换 `shujujituan`、`shujujituan1`、`shujujituan2` 三个本地练习档案，各自保存作答、错题、收藏及模拟卷记录。

记录保存在当前设备、当前浏览器的存储位置，不会随仓库文件自动同步。换电脑、换手机、换浏览器或更改打开路径前，请在“错题收藏”导出 JSON 备份，在目标档案中导入。

更新版沿用旧题号和记录格式。更新前先导出旧记录；如打开新版后未显示历史记录，请在对应档案导入备份。
